# Birthday Surprise

A small, static birthday celebration website. Open `index.html` in a browser to
view it, or publish the project with GitHub Pages.

## Personalize

Edit the `birthdayConfig` object near the top of `script.js` to change the
recipient's name, birthday message, photo, music, and wishes. Keep the photo
path relative to `index.html`; the current photo is `Mamo.jpg`.

The optional music file is in `assets/birthday-music.mp3`.
